# Construct TUI Examples

These are the five built-in starter examples exposed through `construct-tui`.

- `flutter.md`: Flutter / Dart mobile habit tracker
- `go.md`: Go API service for ops monitoring
- `rails.md`: Ruby on Rails room booking app
- `nuxt.md`: Nuxt 3 editorial journal app
- `next.md`: Next.js launch monitoring dashboard

Use them from the TUI with:

```text
/examples
/example show flutter
/example run flutter
```
